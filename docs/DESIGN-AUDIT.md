# K-Sool 화면 개선 기록 · 2026-11-03

현재 테마: 사용자의 후속 요청에 따라 소주병을 떠올리는 초록 `#16845B`, 연한 민트 `#F2FAF6`, 흰색 카드의 라이트 테마로 변경했다. 생성 UI 선언만 변환하며 원본과 픽셀 아트·게임 캔버스의 색상 데이터는 보존한다. 아래 앰버·다크 기록은 이전 작업 이력이다.

사용자 승인: 앰버·골드 + 다크 테마. 대상은 앱인토스 파생 프로젝트 전체이며 원본과 vendor 스냅샷은 변경하지 않았다.

## 반영

| 영역 | 변경 |
| --- | --- |
| 브랜드 | 설정 및 생성 UI의 주 색상을 #D5A64A 계열로 통일. 원본 아이콘 그림은 재색칠하지 않음 |
| 컨테이너 | 앱 내부 상단 브랜드 헤더 숨김, 설정을 하단 탭 영역으로 이동. 파티게임 목록 복귀를 하단 제어 영역에 배치 |

| 조작 | 버튼 최소 영역, 닫기 버튼, 숫자 키패드·시간 선택·게임 탭 크기 보정 |
| 안전 여백 | 탭바·파티게임 하단 및 상단 inset 반영, 짧은 화면에서 스크롤로 제어에 접근 |
| 레이아웃 | 도감 카드 배지를 분리하고 소형 화면의 카드 열 수를 조정. 도감 카테고리는 가로 스크롤. 설정 초기화 영역을 줄바꿈 가능한 구조로 변경 |

| 안정성 | 힌트 BASEBALL/UPDOWN 렌더에서 범위 밖 변수를 참조하던 원본 오류를 생성 단계에서 보정. 뒤로가기 시 실제 모달 close로 게임 정리 실행 |
| 회귀 검증 | CI 시작 감지를 로그 문자열 대신 HTTP 응답으로 변경. 디자인 자동 점검 추가 |

## 검증 범위

- `npm run build`: 타입 확인 + Vite + `.ait` 생성.
- `npm test`: 원본 72개 파일 해시, 원본 백엔드 격리, 첫 조합·저장 복원, 설정, 도감·힌트, 9개 파티게임 진입·복귀, UpDown 결과·재시작.
- `npm run audit:design`: 320×568, 390×844, 844×390에서 주조실·도감·추천·파티 로비·9개 파티게임·설정·힌트, 총 45개 조합. 11px 이하 글자·44px 미만 버튼·문서 가로 넘침 검사.
- 모바일 첫 화면·도감·설정·힌트 및 파티게임 스크린샷 시각 확인. 작은 화면의 스크롤은 의도한 접근 경로다.
- 자동 점검 결과와 캡처는 `test-results/design`에 생성되며 CI 아티팩트에 남는다.

## 판정과 한계

| --- | --- | --- | --- |
| 주조실·결과 | 로컬 확인 | 통과 | 기존 게임 설명 유지 |
| 도감·추천 | 로컬 확인 | 통과 | 기존 데이터 유지, 추천은 기기 로컬 |
| 설정·힌트 | 로컬 확인 | 통과 | 저장 안내 추가, 원본 힌트 오류 보정 |
| 파티 로비·9개 게임 | 로컬 확인 | 통과 | 원본 게임 규칙·해금 유지 |

이 기록의 글자·터치 영역 수치는 design 하네스 기준이다. 공식 문서의 독립적인 인증을 뜻하지 않는다. 공식 게임 출시 가이드 원문에서 safe area, 종료 확인, 시스템 뒤로가기, 백그라운드 사운드 요구를 확인했다. 문서 MCP는 서버 오류를 반환해 공식 웹 원문으로 대조했다.

다음은 코드 수정만으로 확정할 수 없다: 실제 토스 WebView의 상단 내비·닫기·물리 백버튼·시스템 사운드 동작, 게임 등급과 성인 인증 적용 여부, 실제/패러디 브랜드와 이미지 사용 권한, 운영자 연락처·최종 개인정보처리방침. 배포 등록용 이미지 제작과 콘솔 등록/검수는 이번 화면 개선에 포함하지 않았다. 광고·결제는 없는 버전이다.

주류 관련 과장 표현과 원본의 문체 일관성은 별도의 UX 문구 검토 대상으로 남긴다. 사용자 게임의 카피와 소재를 임의로 다른 게임으로 바꾸지는 않았다.
